# Nielsen heuristics — score sheet

Use this when reviewing a screen. One row per issue. Severity is blocker, major, or minor.

1. Visibility of system status — the user can see what is going on (saving, loading, selected, last updated).
2. Match the real world — words and order match how the user talks about the job.
3. User control and freedom — undo, cancel, back, escape from a mistake.
4. Consistency and standards — same thing looks and behaves the same across screens.
5. Error prevention — destructive actions need a confirm or an undo, not a surprise.
6. Recognition rather than recall — options are visible; the user should not have to remember a code or a hidden trick.
7. Flexibility and efficiency — a short path for first use, a faster path for repeat use.
8. Aesthetic and minimalist design — every extra control fights the main job.
9. Help users recognise, diagnose, and recover from errors — plain language, a next step, no blame.
10. Help and documentation — only where the UI cannot be obvious; short and next to the task.
