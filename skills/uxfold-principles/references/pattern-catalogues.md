# Pattern catalogues

Pick one catalogue from `AGENTS.md` product type. Mix only when the product is truly both (for example a consumer app with an admin console — then split by area).

## Enterprise

Default posture — dense but scannable, keyboard-friendly, explicit save.

- Data table with sort, filter, column presence, and a row action menu
- Bulk actions that say how many items are selected
- Empty, loading, error, and “no results for this filter” as four different states
- Permission-aware controls (hidden vs disabled with a reason)
- Audit-friendly copy (“Saved 2 minutes ago by Sam”)
- Destructive action is never the only bright button
- Forms with labels outside the field, validation on blur, unsaved-change warning

## Consumer / friendly product

Default posture — one primary action, progressive disclosure, first success fast.

- One obvious CTA per view
- Onboarding that can be skipped and does not repeat
- Empty state that shows the next action, not a blank card
- Social proof or status only when it helps the job
- Settings buried until needed
- Short, human microcopy (pair with the UX writing skill if installed)
- Paywall or permission prompt after the user has seen value, not before
