# Funnel thinking

Write `docs/funnel.md` when you apply this skill.

## Labels

- TOFU (top) — understand and trust. What is this, why should I care.
- MOFU (mid) — evaluate. Compare, preview, proof, FAQ, constraints.
- BOFU (bottom) — act. Sign up, pay, invite, finish the first success.

For logged-in products map the same idea to acquire → activate → habitual job. Do not turn an admin tool into a landing page.

## Rules

- Every screen you add gets one funnel label. If it has none, it is probably navigation chrome — say so.
- Do not ask for payment or permissions before the user has seen value, unless the product is paid-only by nature.
- One primary action at BOFU. Extra actions go under the fold or into a secondary text button.
- If uxfold-principles is installed, run Pareto on the funnel — one acquisition job, one activation job.
